## Adding a new topic

1. Add the topic under `labs.topics` in [`_meta/taxonomy.yaml`](../_meta/taxonomy.yaml) with `status: active`.
2. Create `labs/<slug>/README.md` using the same course-level template as the Local SEO README.
3. Start synthesizing lessons via PR.
